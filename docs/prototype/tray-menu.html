插件侧 · 只声明

ctx.tray.add_action(
    "start", "开始专注", on_start,
    group="tools",   # quick / tools / status
    order=10,        # 槽内次序
    submenu=None,    # None = 自动裁决
)

基座侧 · 裁决形态

  • 槽内只有一个插件时全部内联，零层级。
  • 槽内出现第二个插件时，各块收进同名子菜单。
  • quick 恒内联、预算 5 条，超出降级到 tools。
  • status 恒只读、预算 3 条，超出截断并告警。
  • tools 预算 6 块，第 7 块起收进「更多插件 ▸」。

排序键（逐层兜底）

slot.order → 槽的固定次序
block.min(order) → 插件块
action.order → 槽内动作
text → full id → 确定性兜底

协议要点

  • 插件声明语义：槽 + 次序 + 文案；形态由基座裁决。
  • 槽固定三档：quick 内联直达、tools 默认、status 只读。
  • tools 内出现第二个插件时，各块自动收进同名子菜单。
  • 基座项（显示主窗口 / 设置 / 退出）永远在最后，插件不可写入。
  • 同 id 覆盖、同 order 按文案兜底、越界与超配额直接拒绝。
  • 超出屏幕：配额 → 收拢 → 截断，最后才是原生滚动。
